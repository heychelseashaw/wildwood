# Wildwood

A private, single-user study reader: a three-year reading plan with a reader, progress tracking and a journal.

- `texts/` holds public-domain books taken from Project Gutenberg (licence pages removed). The public-domain check for each is in `content.js`.
- Copyrighted lectures are linked, never copied.
- Short guides in `content.js` are written by Claude (an AI) and labeled as such in the app.
- No personal data is stored in this repository. Progress and notes live in a private database behind sign-in.

This is not a teacher training, is not accredited, and is not affiliated with AWSNA or WECAN.
